on 2026-08-02. **Everything in `output/` dated 2026-08-02 or earlier predates this
change** and refers to employers that are no longer in the source of truth.

This note exists so those files are not mistaken for current, and so a future run
does not try to reconcile them.

## 2. Why `output/` was not rewritten

`output/` is a record of what was actually generated and, in some cases, sent.
Retroactively renaming employers in 252 files would make them disagree with any
copy an employer already holds, and the 256 PDFs would still show the old names
until regenerated.

**Consequence to be aware of:** `scripts/verify_resume.py` Gate 2 (frozen facts)
validates every company and date in an output against `input/master-resume.md`.
**Existing outputs will now fail that gate.** This is expected. Do not "fix" them
by editing — regenerate from the current master instead.

**If an application is still live, regenerate it.** Do not send a pre-cutover
file.
